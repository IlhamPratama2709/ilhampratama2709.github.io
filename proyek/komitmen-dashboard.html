KOMITMEN dashboard site

Summary

KOMITMEN is a research programme at Universitas Islam Internasional Indonesia with seven workstreams. I built this site so that its eight dashboards sit in one place and a reader can start from a district or province as well as from a topic.

Kota Semarang shows the result. Its page draws figures from all eight dashboards, and its PDF report runs to 36 A4 pages. Every other district and province has a page and report in the same layout, 552 in all.

What the site does

Each dashboard covers one topic: power plants, land subsidence in Java, regional descriptive analysis and regional development plans (RPJMD), industrial decarbonisation, regional finance, regional statistics from BPS, household welfare, and green jobs.

The land subsidence dashboard works at village level. Its map covers 24,689 of Java's 25,366 villages, those with at least 20 radar measurement points, and clicking a village shows its subsidence rate, population, and flood record. GNSS stations on the same map show measured height over time.

Region pages arrange the same data by place. Each page has one section per dashboard, with the area's figures, a comparison, and charts, and it offers the data as CSV and the report as PDF. Some gaps remain. Green jobs figures for six provinces in Papua cannot yet be matched, and those pages say so.

A comparison page plots any two district indicators against each other, even when they come from different dashboards, and it uses the latest year of each indicator that has data for at least 30 districts.

The site is not finished. Regional finance, BPS regional statistics, and household welfare are still marked as internal drafts, and the BPS figures have not been verified.

My role

I built the site, including the region pages and PDF reports, and most of the dashboards. A colleague built the green jobs dashboard.

The data came from the team as well as from public sources. The household welfare dashboard, for example, uses Susenas March 2025 data processed by a colleague. My part there was the dashboard.

Tools

SiteStatic HTML, CSS, and JavaScript, deployed on Cloudflare
BuildPython scripts that copy each finished dashboard into the site and check its data package
DataShared CSV and JSON packages. Survey microdata stay off the site
ReportsA4 print layout that reads the same data as the region pages
Version controlGit and GitHub, in a private repository

Sources shown in the videos include BIG boundaries, Sentinel-1 radar estimates (Ohenhen et al., 2026), Ina-CORS GNSS stations, WorldPop, and PODES.

The land subsidence data package is 21.6 MB, close to Cloudflare's limit of 25 MB per file, so the update script stops if any file passes 24 MB.
